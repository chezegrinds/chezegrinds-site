FAQ

Common questions.

Why no single class option?
Physics and Chemistry build sequentially. Topics covered on Day 2 reference Day 1, and the exam paper classes reference both masterclasses. You get the most value from doing the whole bundle so we only sell it that way.
How does the class work?
It's a live Zoom Webinar. You join from anywhere on phone, laptop or tablet. You only see and hear Ben. Your camera and mic stay off. The Q&A panel is on for the whole class so you can drop a question anytime and get an answer live.
What if I miss part of a class?
Every class is recorded. You get the full replay so you can rewatch or catch up whenever you need to.
Do I get notes?
Yes. You get full course notes for whichever bundle you take, concise but complete coverage of the HL syllabus. Keep them for the run up to the exam.
What's the difference between buying each subject and the combined bundle?
Each subject is €50 on its own. The combined bundle is €80 if you're taking both, so you save €20 by buying them together.
